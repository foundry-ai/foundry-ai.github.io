The exhaustive Peres transform runs Peres's iteration of von Neumann's procedure to exhaustion and keeps everything it does not extract: it is a bijection of {0,1}^N onto pairs (fair bits, residual bits). The fair bits are exactly uniform given the residual for every exchangeable law. For a Bernoulli source the residual bits have explicit biases, which gives lossless codes in which only the residual is coded: code B (arithmetic coding of the residual) and code C (Rice codes, no arithmetic coder). For sources with memory, the Burrows–Wheeler transform of the reversed string arranges all context orders in one binary tree of intervals.
